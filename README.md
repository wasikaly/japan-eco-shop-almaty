# Japan Eco Shop — Алматы

Статический сайт-витрина японской косметики и бытовой химии (Алматы, Казахстан).

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Разметка страницы |
| `style.css` | Стили |
| `script.js` | Каталог товаров, поиск, фильтры, корзина |
| `images/` | Логотип, фото магазина и товаров |
| `vercel.json` | Конфигурация деплоя на Vercel |

## Локальный запуск

Отдельная сборка не нужна — это обычная статика. Достаточно открыть `index.html`
в браузере или поднять простой сервер:

```bash
python -m http.server 8000
```

## Деплой на Vercel

1. Vercel → **Add New… → Project** → **Import Git Repository** → выбрать этот репозиторий.
2. Framework Preset: **Other**. Build Command оставить пустым.
3. Output Directory: `.` (уже задано в `vercel.json`).
4. **Deploy**.

Дальше каждый push в ветку `main` деплоится автоматически.

## Цены

Прайс хранится в массиве `products` в начале `script.js`:
`priceKzt` — оптовая цена, `retailKzt` — розничная (её видит покупатель).
Актуализировано по прайс-листам за июль.
